**One keyboard for all your languages, without switching keyboards across apps or mid-sentence.**

Stay on a clean English ASCII layout across Figma, Blender, Overleaf (`\cite{}`), games (`WASD`), terminal/IDE workflows, and everyday chats between WhatsApp, Mail, Excel, WeChat, LINE, and Slack. Press **Caps Lock** (or tap **Convert** on mobile) to convert phonetic input into native script in place while keeping English terms untouched.
